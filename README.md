# テンポスイッチ — GitHub Pages / PWA

A・B・Cの3種類のBPMをあらかじめ設定し、好きな順番で登録して、大きなボタンのワンタップでテンポを切り替えるメトロノームです。**iPhone／Android／PCに対応**します。

## 使い方

1. 上段の A / B / C の「−」「＋」で BPM を設定します。**数字を直接タップして入力**することもできます（30〜300 BPM）。
2. 中段の「＋A」「＋B」「＋C」を順番にタップすると末尾に追加されます。**並んだ文字をタップすると、その1ステップを削除**できます。「戻す」は直前の編集を取り消し、「全消去」はすべてを削除します。
3. 下段の **「再生スタート」** を押すと、シーケンス1番目のテンポで音が鳴ります。以後、**大きな「次のテンポへ」ボタンを押すたびに、即座に次のテンポへ**移ります。最後の文字の次は先頭に戻ります。
4. 「停止・先頭へ」で止められます。「音 ON/OFF」で無音のビジュアルモードにもできます。

初期設定は A=100 / B=120 / C=110、順番は **B A B A B A B A B C**（120→100→120→100→120→100→120→100→120→110）です。

**補足：** ビートは4拍ごとに1拍目の音が高くなります。テンポを切り替えると、その瞬間に新しいテンポの1拍目から始めます。シーケンス編集は再生を停止・先頭にリセットします。A/B/C の数値変更は、再生中でも反映されます。ブラウザー・OSの仕様により画面ロック中の音声再生は保証されません。

## GitHub Pages で無料公開

1. GitHubにログインし、`New repository` で新しいリポジトリ（例：`tempo-switch`）を作成します。`Public` にします。
2. このZIPを解凍し、**`index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest`、`icons` フォルダーをリポジトリの直下へ**アップロードしてください。ZIPファイル自体ではなく、中のファイルをアップロードします。
3. リポジトリの `Settings` → `Pages` で、`Build and deployment` → `Source: Deploy from a branch`、`Branch: main`、`Folder: /(root)` を選んで `Save` します。
4. 公開URLは通常 `https://ユーザー名.github.io/tempo-switch/` です。GitHub Pagesの画面に表示されたリンクから開いてください。

**iPhoneでアプリとして使う**：Safariで公開URLを開き、共有メニュー →「ホーム画面に追加」を選びます。**Android**：Chromeで開き、メニュー →「アプリをインストール」または「ホーム画面に追加」を選びます。インストールしなくてもブラウザーで動作します。

**オフライン対応**：公開ページを一度オンラインで読み込み、Service Worker の登録とキャッシュ保存が完了したあとは、オフラインで起動できます。初回起動時のサウンドはボタン操作後に再生されます（ブラウザーの制約）。設定と順番はブラウザー内に保存されます。

## 更新するには

GitHubのファイルを変更してください。画面が古いままの場合は、`sw.js` 内の `CACHE_NAME` を例えば `tempo-switch-offline-v2` に更新すると、次回読み込み時に新バージョンへ切り替わります。ホーム画面に追加したPWAは再起動が必要になる場合があります。

## ファイル一覧

- `index.html` — 1画面のUI
- `styles.css` — スマホ／PCのレスポンシブデザイン
- `app.js` — シーケンス編集、Web Audioのメトロノーム、設定保存
- `manifest.webmanifest` — PWAの名称・起動形式・アイコン
- `sw.js` — オフラインキャッシュ
- `icons/` — アプリアイコン（192 / 512）

すべて静的ファイルです。サーバーや有料APIは不要です。
